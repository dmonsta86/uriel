# Community and maintenance

Uriel improves through reproducible reports, transparent corrections, and
bounded proposals.

## Report classes

- software bug;
- audit false positive;
- audit miss;
- documentation correction;
- translation correction;
- feature proposal;
- Forge Trial proposal;
- private security report.

## Ground truth

Scientific-audit reports must identify the basis for calling a result correct
or incorrect.

An AI answer alone is not ground truth.

## Public conduct

Discuss the artifact, method, finding, and evidence.

Do not attack an author's character, competence, or intent.

## Closure

Confirmed bugs and audit errors should create a regression test and link the
fixing release.
