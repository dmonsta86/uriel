# Accessibility and anti-elitism commitments

Uriel is intended for students, independent researchers, underfunded labs, community investigators, maintainers, and curious people—not only institutions with subscriptions and compute budgets.

## Product rules

- Core research organization and integrity checks remain offline and free.
- No finding uses credentials, affiliation, age, fluency, or prose polish as a quality signal.
- The original question is preserved before reformulation.
- Clarification questions are limited to facts that materially change a claim, test, control, or interpretation.
- Refusals are specific, neutral, reversible, and retained as reminders.
- Every blocker has three repair paths, including a minimal-cost route where possible.
- AI is an optional accelerator, never an admission ticket.
- JSON output supports assistive tooling and automation; Markdown output remains readable in basic editors.
- Documentation explains current free and low-cost routes without pretending quotas are permanent.

## Language and interface roadmap

Version 1 is English-first and terminal-first. Priorities for contributors include:

- plain-language field labels and guided forms;
- translations maintained by native speakers;
- screen-reader testing and non-color status cues;
- a local browser UI served from the standard library;
- discipline-specific examples for non-programmers;
- lower-memory source indexing and resumable scans;
- printable worksheets for users with intermittent computer access.
