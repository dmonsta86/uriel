# Synthetic preregistered analysis plan

**This is a fictional benchmark file.**

## Sample

Thirty graduate researchers.

## Assignment

Participants use their existing work rooms. This is not randomized.

## Primary outcome

Change in task completion time from baseline to week 4.

## Secondary outcomes

```text
accuracy percentage
self-reported stress
experience subgroup
```

## Exclusions

Exclude only a participant missing more than one weekly session.

Do not exclude a participant because the observed result is inconvenient.

## Analysis

- join participant and outcome files by `participant_id`;
- inspect duplicate IDs before analysis;
- refuse ambiguous IDs;
- use change from baseline;
- report missingness;
- describe room assignment and room differences as confounding;
- do not use causal language;
- treat subgroup analyses as exploratory;
- identify all deviations from this plan.
