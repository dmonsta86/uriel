# Support

## Bugs and reproducible audit errors

Use the structured GitHub Issue Forms.

## Questions, broad feedback, and early ideas

Use GitHub Discussions when enabled.

## Security

Use the private reporting route in `SECURITY.md`.

## Research interpretation

Uriel is a research-development and assurance tool. It does not replace domain,
ethics, legal, medical, statistical, or peer-review judgment.

## Sensitive work

Do not attach unpublished or restricted research unless you have the right to
share it and it is necessary for reproduction. Prefer a synthetic fixture.
